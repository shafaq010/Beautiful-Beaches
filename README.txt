BEAUTY OF BEACHES — ISLAND BEACH ADVENTURES
============================================
Design direction: cinematic tropical-island theme inspired by the latest reference image.
Visual style: dark teal overlay, turquoise ocean photography, elegant script headings, minimal transparent navigation and warm sand accents.

18 separate HTML pages:
1. index.html — Home
2. beaches.html — Beaches
3. north.html — North zone
4. south.html — South zone
5. east.html — East zone
6. west.html — West zone
7. gallery.html — Gallery
8. booking.html — Booking enquiry
9. about.html — About Us
10. contact.html — Contact Us
11. queries.html — Queries / FAQ
12. feedback.html — Feedback
13. sitemap.html — Site Map
14. help.html — Help
15. login.html — Login
16. privacy.html — Privacy Policy
17. terms.html — Terms & Conditions
18. travel-guide.html — Travel Guide

Technologies: HTML5, CSS3, Bootstrap 5, JavaScript and jQuery.
Common assets: assets/css/style.css, assets/js/main.js, assets/images/logo.svg.

Run:
1. Extract the ZIP.
2. Open the extracted folder in VS Code.
3. Open index.html with Live Server.
4. Internet is required for Bootstrap, jQuery, Google Fonts and Unsplash images.

Requirements / functionality:
- Responsive navigation with zone dropdown and hover/active states.
- Custom BeautyOfBeaches SVG logo.
- Visitor count stored in browser localStorage.
- Scrolling ticker with live device date and time.
- Optional HTML5 geolocation button on the Help page is available if browser permission is granted.
- Gallery, feedback, sitemap, about, queries, contact and separate zone pages.
- Booking page includes North, South, East and West options and external flight/road planning links.
- Print / Save as PDF action on Help page.

Important:
- Booking, Login, Contact and Feedback are front-end demos only; no backend/database or real booking/payment is connected.
- Contact details are sample placeholders; replace with actual organization information before submission.
- Beach photos are remote Unsplash images and need internet.
- This project uses separate HTML files as requested; navigation is multi-page rather than a single-page application.
- Browser location permission is optional and is not requested automatically.

Gallery update: includes 8 local beach photographs displayed in a 4-column by 2-row grid on large screens. Click any thumbnail to open a full-size image carousel at that exact photo. Use Previous/Next arrows or the 8 slide indicators inside the viewer to browse all gallery photos without leaving the page.
